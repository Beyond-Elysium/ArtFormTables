# @artform/suite-ui

Shared Tabler-based UI kit for ArtForm's standalone products (Arvo and the
other products being built on top of `@tabler/core`).

**Status:** placeholder scaffold, added from `apps/arvo` so it has a real
workspace package to depend on (`theme.css` import, `CsvImportWizard`
component). The real implementation is being built out in parallel in a
separate worktree — merge that work in here rather than starting over.
